# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or can be used on a single-package repo to great effect.

We have a `config.json` here with a few things configured:

- `commit`: Enables committing when running `changeset version`
- `baseBranch`: Tells changesets to use the specified base branch
- `linked`: Groups packages that should always be updated together
- `access`: Determines if the packages should be published as public or restricted on the registry
